# 자율주행 시리즈 개편과 Data Flywheel 글 발행

## 변경
- 기존 25편 URL·발행일을 유지하고, 새 Data Flywheel 글을 포함해 26편을 6개 시리즈로 구성했다.
- 토폴로지 홈은 전체 화면 그래프만 유지하고, Log에서 시리즈로 진입한다. 시리즈별 읽는 순서와 글의 현재 위치·이전/다음 글을 확인할 수 있다.
- scene/sample, MCAP·ROS, 시간 정합, 평가·시뮬레이션 설명과 관련 용어사전을 교정했다. 26편에 참고 자료를 연결했다.
- 새 글은 Portal/Pipeline 책임, 재현성, 데이터 누수, 지표와 2026-10-03 기준 네 기업의 공개 발표·분석을 다룬다.

## 검증
- Node 시리즈 회귀 검사 4개 통과: 6개 분류·26편 구성, 순서·경계, 내부 링크·참고 자료, 기존 URL 유지.
- Next 프로덕션 빌드(타입 검사·린트 포함)와 사이트맵 생성 성공.
- 로컬 운영 모드에서 35개 경로 HTTP 200, 미등록 시리즈 HTTP 404 확인.
- 데스크톱·390px 모바일, 밝은/어두운 테마, 키보드 목차, 용어 팝업, Log 진입점 확인.
- 별도 스펙 리뷰와 코드 품질 리뷰 수행. 지적된 본문 순서와 요약 문구 수정.

## 배포·인수인계
- GitHub main → AWS Amplify 자동 배포. 앱 d2ni4q25bisiz5, 서울 리전. 운영 주소 https://www.0biglife.com.
- 원본 체크아웃의 미발행 글·썸네일·용어 UI 수정은 보존했다. 이 변경은 codex/av-series-final 작업 트리에서 작성했다. 원본 폴더에 있던 Data Flywheel 초안은 별도 보존되어 있으므로 이후 동기화 때 이번 발행본과 대조한다.
- 로컬 GA 자격 증명은 복사하지 않았다. 운영 분석 설정은 변경하지 않았다.
- 생성 사이트맵은 빌드에서 갱신한다. 의존성·프레임워크·배포 설정 변경 없음.

## 이후 관리
- 새 글은 기존 series ID와 다음 seriesOrder를 frontmatter에 지정한다. 기존 순서를 바꾸면 이전/다음 링크도 자동으로 바뀐다.
- 이후 글이 늘면 회귀 검사에 고정한 총 편수도 함께 갱신한다.
- 산업 동향은 날짜가 있는 분석이다. 후속 발표가 나오면 출처와 확인일을 갱신하고 발표와 검증 결과를 계속 구분한다.
- 모든 예제의 실행이나 자율주행 전체 분야의 전문 심사를 완료했다는 의미는 아니다. 예시 코드의 어댑터와 가정은 본문에 명시했다.
